Informazioni sulla privacy

I dati sono salvati nel database locale del browser (IndexedDB) sul dispositivo che stai usando. Non vengono inviati a un server da questa applicazione. Chi usa lo stesso profilo del browser o ha accesso al dispositivo potrebbe comunque accedervi. La cancellazione dei dati del browser può eliminare l'archivio: effettua backup regolari. GitHub Pages pubblica il sito e il suo codice, non rende privati i contenuti del sito. Non caricare informazioni personali o documenti riservati su un repository pubblico.

Nuova mappa

Gli allegati vengono conservati nel browser. File molto grandi possono occupare spazio sul dispositivo.
